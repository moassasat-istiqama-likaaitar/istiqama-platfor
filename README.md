# منصة الاستقامة الرقمية — النموذج التفاعلي للواجهة

نموذج تفاعلي (Prototype) للواجهة الأمامية لمنصة الاستقامة، مبني بـ **Vue 3** وبيانات تجريبية، ليُسلَّم للشركة المنفذة كأساس لبناء الخلفية (Laravel).

## التقنيات

| الجزء | الأداة |
|---|---|
| الإطار | Vue 3 (Composition API) + Vite |
| مكتبة المكونات | PrimeVue 4 (ثيم Aura، يدعم RTL) |
| إدارة الحالة | Pinia |
| التوجيه | Vue Router (hash) |
| تعدد اللغات | vue-i18n — العربية (RTL)، الفرنسية والإنجليزية (LTR) |
| الخط | Cairo |

## التشغيل

```bash
npm install
npm run dev      # بيئة التطوير
npm run build    # نسخة النشر في dist/
```

النشر على GitHub Pages تلقائي عند كل دفع إلى `main` (`.github/workflows/deploy.yml`).

## البنية

```
src/
  api/         ← عقد الـ API: كل دالة = نقطة نهاية (الطريقة والمسار مكتوبان فوقها)
  mock/        ← البيانات التجريبية (تُحذف عند الربط)
  stores/      ← الجلسة (auth) والإشعارات والرسائل (inbox)
  config/      ← القوائم لكل دور، الثيمات، أنواع الإشعارات
  i18n/        ← الترجمات
  layouts/     ← قالب الدخول وقالب التطبيق
  components/  ← المكونات المشتركة
  views/       ← الشاشات
```

## مبادئ متفق عليها

1. **شخص واحد = حساب واحد بعدة صفات.** الصفة = دور + مدرسة + (أقسام | أبناء | مستويات). مثال: معلم في مدرستين وولي في نفس الوقت. بعد الدخول يختار الشخص صفته، ويبدّل بينها من رأس الصفحة.
2. **ثلاثة قوالب للتلاميذ، تختلف في البنية لا في الألوان فقط:**
   | | البراعم (1-3 ابتدائي) | المستكشفون (4-5 ابتدائي و1 متوسط) | الشباب (من 2 متوسط) |
   |---|---|---|---|
   | التنقل | لوحة أزرار سفلية كبيرة | رأس بتبويبات + بطاقة المستوى (XP) | شريط جانبي بالمقررات + بحث دائم |
   | الرئيسية | مهمة اليوم + مربعات المواد | لوحة المهام + مناطق الاستكشاف | مخطط الأسبوع + جدول المقررات |
   | المادة | خريطة محطات لكل محور | فصول (محاور) قابلة للطي | مخطط المقرر في جداول |
   | الدرس | خطوات متتالية بأزرار كبيرة | المحتوى + قائمة مهام الدرس | وضع القراءة + ملاحظاتي الشخصية |
   | الاختبار | تصحيح فوري لكل سؤال | مؤقّت ونقاط خبرة | شبكة تنقل بين الأسئلة + علامة مراجعة |
   | التقدّم | لوحة ملصقات وأنابيب | طريق المستويات والشارات | لوحة تحليلات ومنحنى العلامات |
3. **المواد والمحاور والدروس** مأخوذة من شيت "سيرورة الدروس" (البرنامج الموحد)، دون القرآن الكريم حالياً. مقررات الإناث تظهر لأقسام الإناث فقط.
4. **الربط بالخلفية:** الشاشات لا تعرف مصدر البيانات؛ تستدعي دوال `src/api/` فقط. عند الربط يُستبدل جسم كل دالة بطلب HTTP إلى المسار المكتوب فوقها. التفاصيل في `docs/api-contract.md`.
5. **وضع العرض:** قائمة الحسابات التجريبية في صفحة الدخول خاصة بالنموذج وتُحذف عند الربط. كلمة مرور كل الحسابات التجريبية: `1234`.
