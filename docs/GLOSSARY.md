# قاموس المصطلحات — مفهوم واحد = عبارة واحدة

**القاعدة:** لكل مفهوم في المنصة عبارة واحدة، تُستعمل نفسها في كل الواجهات والوثائق ودفتر الشروط.
الاستثناء الوحيد: ثيمَا **البراعم** و**المستكشفين** لهما مفردات ودّية خاصة بهما (الجدول الثاني)، ثابتة داخل كل ثيم.

يفحص `npm run terms` نصوص الواجهة تلقائياً قبل كل بناء، ويوقف النشر إن وجد عبارة مرفوضة (`scripts/check-terms.mjs`).

## المصطلحات المعتمدة

| المفهوم | العبارة المعتمدة | المرفوض |
|---|---|---|
| من يدرّس | معلم / معلمة | أستاذ، أستاذة |
| المتعلّم | تلميذ / تلاميذ | طالب، طلاب |
| ولي التلميذ | الولي / الأولياء | ولي الأمر، أولياء الأمور |
| مسؤول المدرسة على المنصة | مدير المدرسة | مدير المنصة المدرسية |
| النشاط الإلكتروني المصحَّح آلياً | **تقييم** / التقييمات (منشئ التقييمات) | اختبار، Quiz، كويز |
| الاختبار الورقي في القسم | **الاختبار الحضوري** (بنك الاختبارات الحضورية، اختبارات الرزنامة) | تقييم حضوري |
| العمل المنزلي | واجب / الواجبات | مهمة (خارج ثيم المستكشفين) |
| الواجبات والتقييمات معاً | الأنشطة (بنك الأنشطة) | الأعمال |
| تقدير التلميذ أو المعلم للمحتوى بالنجوم | **التقدير** | التقييم |
| مخزن المحتوى المعتمد لكل المعلمين | المكتبة المركزية | المحتوى الرقمي، المكتبة الرقمية |
| محتوى قسم معيّن | مكتبة القسم | — |
| رسالة جماعية من الإدارة أو المدرسة | **إعلان** / الإعلانات | إشعار المدرسة |
| تنبيه آلي في الجرس | **إشعار** / الإشعارات | تنبيه |
| صفحة تقدّم التلميذ | تقدمي | تتبعي الدراسي، التحليلات |
| قرار مدير المدرسة على محتوى معلميه | **مصادقة** ← الحالة «معتمد مؤقتاً» | — |
| قرار المحرر | **اعتماد** ← الحالة «معتمد» | — |

## مفردات الثيمات (للتلاميذ الصغار فقط)

| المفهوم | البراعم | المستكشفون | الشباب (= المعتمد) |
|---|---|---|---|
| الرئيسية | بيتي | لوحة المهام | الرئيسية |
| دروسي | دروسي | المواد | دروسي |
| الواجبات والتقييمات | تحدياتي | سجل المهام | واجباتي وتقييماتي |
| مكتبة القسم | مكتبتي | مكتبة القسم | مكتبة القسم |
| تقدمي | نجومي | إنجازاتي | تقدمي |
| النقاط | نجوم | نقاط | نقاط |

## مسائل مفتوحة تنتظر قرار صاحب المشروع

| المسألة | التعارض |
|---|---|
| **الفصل أم السداسي؟** | المواسم مقسّمة إلى 3 فصول، وبنك الاختبارات الحضورية يستعمل «السداسي» (2) |
| **«نشاط» تصنيفاً للمحتوى** | يتعارض مع «الأنشطة» (الواجبات والتقييمات) في «بنك الأنشطة» |
| **الصفة أم الدور؟** | «اختيار الصفة» عند الدخول، و«الأدوار والصلاحيات» في الإعدادات |
| **ملفات أم محتوى؟** | «رفع محتوى»، و«مصادقة ملفات المعلمين»، و«ملفاتي وأنشطتي» |
